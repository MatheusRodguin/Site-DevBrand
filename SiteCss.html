O que é CSS

CSS é uma linguagem de folhas de estilo usada para definir a apresentação e o visual de páginas web, criada com foco na separação entre conteúdo e design. Sua sintaxe declarativa permite estilizar layouts complexos com poucas regras, sendo a escolha padrão para responsividade, animações, tipografia e interfaces modernas.

Sua sintaxe limpa permite escrever programas complexos com poucas linhas, sendo a escolha favorita para Inteligência Artificial, Ciência de Dados, Automação e Web.

primeiro_style.css
# Exemplo básico em Css .saudacao {
color: #2563eb;
font-family: Arial, sans-serif;
font-size: 20px;
}

Estilização

A estilização define cores, fontes, margens e espaçamentos para deixar cada página visualmente atraente.

Flexbox

O Flexbox organiza elementos em linha ou coluna, facilitando o alinhamento responsivo na página.

@media (max-width: 900px)

Responsividade

A responsividade adapta o tamanho dos elementos para garantir boa leitura em qualquer tela.

for / while
