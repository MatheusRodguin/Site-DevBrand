O que é Python?

Python é uma linguagem de programação de alto nível, interpretada e de propósito geral, criada com foco na legibilidade do código.

Sua sintaxe limpa permite escrever programas complexos com poucas linhas, sendo a escolha favorita para Inteligência Artificial, Ciência de Dados, Automação e Web.

primeiro_script.py
# Exemplo básico em Python def saudacao(nome): mensagem = f"Olá, {nome}! Bem-vindo ao Python." return mensagem usuario = "Dev" print(saudacao(usuario))
