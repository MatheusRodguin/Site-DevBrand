O que é HTML?

HTML (HyperText Markup Language) não é uma linguagem de programação, mas sim uma linguagem de marcação.

Ela funciona como o esqueleto de um site, usando "tags" para dizer ao navegador o que é um título, um parágrafo, um botão ou uma imagem.

estrutura-basica.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <title>Minha Página</title>
</head>
<body>
  <h1>Olá, Mundo!</h1>
  <p>Meu primeiro site em HTML.</p>
</body>
</html>

Principais Tags para Começar

<h1> a <h6>

Títulos e Subtítulos

Definem a hierarquia dos títulos da página, sendo o h1 o mais importante e o h6 o menor.

<p>

Parágrafos

Utilizada para inserir blocos de texto comuns e organizar o conteúdo escrito da página.

<a href="">

Links de Navegação

Cria hiperlinks que conectam uma página à outra ou levam o usuário para sites externos.

<img src="">

Imagens

Permite exibir fotos, ícones e ilustrações na tela a partir de um arquivo local ou URL.

<div>

Contêineres

Agrupa elementos em blocos para facilitar a organização e a estilização posterior com CSS.

<button>

Botões Interativos

Cria botões clicáveis para enviar formulários ou disparar ações na interface do usuário.
